print3d_ONE نسخه رایگان

این نسخه کاملاً استاتیک است و برای GitHub Pages مناسب است.
برای آنلاین کردن:
1) یک حساب GitHub بساز.
2) یک Repository با نام print3d-one بساز.
3) index.html را داخل Repository آپلود کن.
4) Settings > Pages > Deploy from branch > main > /root را انتخاب کن.
5) آدرس سایت به شکل username.github.io/print3d-one خواهد شد.

نکته: پنل این نسخه فقط روی همان مرورگری که استفاده می‌کنی ذخیره می‌شود و برای مدیریت مشترک آنلاین/درگاه واقعی مناسب نیست.
